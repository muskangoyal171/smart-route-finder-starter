# `.gitignore` — File Guide

## Purpose

This file tells Git which generated or machine-specific files should not be committed. It helps keep the repository portable between the student's computer, VS Code, and other contributors' machines.

## Current rules

- `target/`: ignores Maven build output so compiled classes and packaged artifacts are not accidentally committed.
- `.idea/`, `.vscode/`, and common IntelliJ module files: ignores local IDE settings that should not be required to build the application.
- `.DS_Store` and `Thumbs.db`: ignores operating-system display metadata.
- `*.log`: ignores local log files.

## Maintenance

Add a new ignore rule only when it applies to generated or local-only files. Do not ignore source code, test code, source data needed to run the app, or documentation. Review new rules carefully because overbroad ignore patterns can hide important project files.

## Verification

Git's view of ignored/untracked files can be inspected with `git status --short` and `git check-ignore -v <path>` after the repository is initialized.
